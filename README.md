# Skeleton2D Modular Character — Godot 4.8

Демо модульного 2D-персонажа на `Skeleton2D` / `Bone2D` по мотивам официального
примера *2D Skeleton* (godot-demo-projects/2d/skeleton), но с полным набором механик:

- **Анимации** (AnimationPlayer + AnimationTree): стойка, ходьба, бег, прыжок, падение,
  приземление, кувырок, присед (стойка и ходьба), скольжение, вис на уступе, подтягивание,
  вставание после рагдолла, прицеливание с пистолетом, выстрел, перезарядка, джеб и кросс.
- **Прицеливание за курсором**: торс, шея, голова и обе руки доворачиваются на курсор (двухкостный IK),
  вторая рука держит пистолет за точку `SupportGrip`, отдача при выстреле, разворот персонажа к курсору,
  ходьба спиной (анимация проигрывается в обратную сторону).
- **IK ног «как в 3D»**: лучи под стопами находят ступени/склон, стопы ставятся на поверхность,
  таз опускается к нижней стопе, поднятая стопа выносится вперёд, стопа поворачивается по нормали. Включение/выключение — `T`.
- **Уступы**: прыжок к стене — персонаж цепляется руками (IK кистей кладёт кисти на угол), `Space` — подтянуться, `S` — отпустить.
- **Крутые склоны**: скольжение (угол больше `floor_max_angle`).
- **Рагдолл**: собран в сцене из `RigidBody2D` + `PinJoint2D` с угловыми лимитами. Включается от взрыва,
  жёсткого падения, клавиши `K` (у манекенов — от пули/удара), затем персонаж встаёт с плавным переходом к анимации.
- **Бокс**: `F` — серия джеб/кросс, хитбокс на кисти толкает бочки и роняет манекены.
- **Взрывные бочки** с цепной реакцией, тряска камеры, частицы.
- **Кастомизация**: каждая часть тела — отдельный `Sprite2D` под своей костью (голова, торс, таз,
  плечо, предплечье, кисть, бедро, голень, стопа — по 3 части на руку и ногу). Экипировка — отдельные
  спрайты (кепка, каска, наколенники, налокотники, рюкзак). Наборы внешности — ресурсы `CharacterSkin`.

Всё, что можно, сделано **сценами и ресурсами**, а не кодом: риг, кости, спрайты, рагдолл, суставы,
модификаторы, дерево анимаций — в `character_rig.tscn`; клипы анимаций — в `character_animations.tres`;
скины — в `.tres`; уровень — обычные узлы. Скрипты только исполняют логику и настраиваются из инспектора.

Проверено на **Godot 4.8-dev6** (headless-импорт, smoke-тест и рендер под Xvfb). Рендер — Compatibility (GL).

## Управление

| Действие | Клавиши |
|---|---|
| Движение | `A`/`D`, стрелки |
| Шаг (медленно) | `Shift` (удерживать) |
| Прыжок / подтянуться на уступе | `Space`, `W`, `↑` |
| Присед / отпустить уступ | `S`, `↓`, `Ctrl` |
| Кувырок | `C` |
| Прицел | правая кнопка мыши (удерживать) |
| Выстрел | левая кнопка мыши |
| Перезарядка | `R` |
| Удар кулаком | `F`, средняя кнопка мыши |
| Рагдолл (тест) | `K` |
| IK ног вкл/выкл | `T` |
| Экипировка | `1` кепка, `2` каска, `3` наколенники, `4` налокотники, `5` рюкзак |
| Следующий скин | `6` |
| Рестарт / выход | `F5` / `Esc` |

Панель кастомизации есть и в HUD (справа сверху).

## Как устроен риг

Иерархия костей (`Visual/Skeleton2D`), персонаж смотрит вправо, начало координат — между стопами на полу:

```
Hips
├─ Torso ─ Head
│  ├─ UpperArm_F ─ Forearm_F ─ Hand_F  (передняя рука; на кисти Pistol и PunchHitbox)
│  └─ UpperArm_B ─ Forearm_B ─ Hand_B  (задняя рука)
├─ Thigh_F ─ Shin_F ─ Foot_F           (передняя нога)
└─ Thigh_B ─ Shin_B ─ Foot_B           (задняя нога)
```

Кости названы «передняя/задняя», а не «левая/правая», потому что персонаж разворачивается
через `Visual.scale.x = -1`; все модификаторы работают в мировых координатах и учитывают зеркало.

- У каждой кости задан `rest`, `length` и `bone_angle` (направление кости) — их используют IK и рагдолл.
- Спрайт части тела лежит под своей костью и помечен метаданными `part_slot` (например `shin`);
  экипировка — метаданными `gear_id` (например `knee_pads`). Риг собирает их автоматически.
- Порядок отрисовки задан `z_index` костей: задние конечности `-2`, передняя нога `1`, передняя рука `2`, голова `1`.

### Модификаторы (аналог SkeletonModificationStack2D)

После применения анимации (`AnimationMixer.mixer_applied`) риг по очереди вызывает `apply()` у детей узла
`Modifiers`: `LegIK_F/B`, `ArmIK_F/B` (TwoBoneIK2D), `FootIK`, `AimIK`, `HandsIK`. Порядок узлов = порядок применения.
Встроенные `SkeletonModification2D*` не используются: они помечены экспериментальными и ломаются при `scale.x = -1`.

### AnimationTree

`BlendTree`: `state` (Transition со всеми локомоционными состояниями, TimeScale для walk/run/crouch_walk)
→ `aim` (Blend2 с фильтром на верхнюю часть тела, поза `aim_pistol`) → `punch` (OneShot, выбор джеб/кросс через
Transition `punch_sel`) → `reload` (OneShot) → `shoot` (OneShot) → output. Все слои верхней части тела фильтруют
только кости торса, шеи, головы и рук, поэтому ноги продолжают идти/бежать во время стрельбы и перезарядки.

### Рагдолл

Узел `Ragdoll` содержит 11 `RagdollBody2D` (капсулы, `top_level = true`, инерция задана явно) и 10 `RagdollJoint2D`
(`PinJoint2D` держит точку сустава). Угловые лимиты PinJoint2D для рагдолла не годятся (они измеряют направление
между центрами тел в мировых координатах), поэтому лимиты считаются в `Ragdoll2D._physics_process` по реальному
относительному углу тел: при нарушении гасится уводящая относительная угловая скорость и тело вместе со всем,
что за ним, поворачивается вокруг точки сустава обратно в диапазон; внутри диапазона действует слабая «мышечная»
пружина к позе покоя. Параметры сустава в инспекторе: `limit_lower`, `limit_upper`, `rest_angle` (для персонажа,
смотрящего вправо; при развороте зеркалируются). При копировании позы на кости локальные углы дополнительно
клэмпятся лимитами, так что визуально анатомия соблюдается всегда. При активации тела ставятся по текущей позе
костей, получают импульс (конечности — меньшую долю, чтобы «болтались»); после деактивации поза за `recover_time`
сводится к анимации.

## Как добавить свою часть тела или экипировку

1. Положите SVG/PNG в `character/parts` (арт рисуется в 4x, спрайт со `scale = 0.25`).
2. В `character_rig.tscn` добавьте `Sprite2D` под нужную кость, задайте `position`, `z_index`
   и метаданные `gear_id` (для съёмной экипировки) или `part_slot` (для замены слота).
3. Для скина создайте новый `CharacterSkin` (`.tres`), укажите текстуры слотов и список `gear`.
   Добавьте его в массив `skins` у `HUD`, чтобы он появился в выпадающем списке.

## Как добавить анимацию

Откройте `character_rig.tscn`, выберите `AnimationPlayer` — все клипы лежат в библиотеке
`character_animations.tres` и редактируются в панели анимации (треки `rotation_degrees` костей и `position` таза).
Новое локомоционное состояние добавляется входом в `state` (AnimationTree), верхняя часть тела —
через OneShot/Blend2 с фильтром на верхние кости.
